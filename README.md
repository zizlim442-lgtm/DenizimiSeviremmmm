# 🤍 Sevgilim Deniz

Romantik sevgi saytı — Deniz üçün.

## Xüsusiyyətlər
- ✨ Animasiyalı ürəklər və hissəciklər
- 🎵 Musiqi əlavə etmək mümkündür
- 📱 Mobil uyğun dizayn
- ❤️ Klikləyəndə ürək effekti

## Musiqi əlavə etmək
1. İstədiyin mahnını `music.mp3` adı ilə bu qovluğa qoy
2. Saytı aç və yuxarı sağdakı **Musiqi** düyməsinə bas

## GitHub Pages-də yerləşdirmək
1. Bu qovluğu GitHub repositoriyasına yüklə
2. Settings → Pages → Source: `main` branch / root
3. Bir neçə dəqiqə sonra saytın hazır olacaq

## Fayllar
- `index.html` — əsas səhifə
- `style.css` — dizayn və animasiyalar
- `script.js` — ürəklər və musiqi
- `music.mp3` — (özün əlavə et)
